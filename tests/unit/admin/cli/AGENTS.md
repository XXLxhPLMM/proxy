# tests/unit/admin/cli/ — `proxy-cli`（管理命令层）五档的判据

本目录只答一件事：`proxy-cli` 这一圈，**哪几处不许漂**。
机制归 `src/admin/`（传输层：解析 / 派发 / 渲染）与 `src/ops/`（数据源操作层：装配 / 读 / 写 /
账本读 / 配置事实）两处文件头；这里只是它们的行为面与层边界的牙齿。

## 共享的不变量（五档共用，逐条配了变异实测）

① ⚠️ **判据只有一份**：`--expires` 的时刻形态、`--quota` / `--window` 的数值形态、名单条目语法，
   三者的判据全部取自数据源层 / 名单规则层，CLI **不重写**。
   「CLI 认得、代理不认得」是最坏的失败形态 —— 用户以为设上了，而代理不认。
   ⚠️ 这条不是洁癖：`Date.parse("2027-01-01")` 返回一个**有限值**、`Date.parse("2027-01-01 00:00")`
   返回**本地**午夜，于是 CLI 自己判的话，同一份配置在 UTC 机器与 +08:00 机器上差 8 小时，
   而运维写它时心里想的一定是本地零点。
   牙齿：`users.test.ts`（`--expires` 五档负向 + 两档正向 + `--window` 挂在无 quota 的账号上）、
   `acl.test.ts`（条目非法要点名那个条目并给出该组的正确语法）。
② **坏内容不许被当成空表改写**：数据源层的读语义是「坏内容 → 保留上一份 / 空表 + 一个 `error`」，
   那对**代理**是对的（判据永不因手滑失效），对**要写数据的工具**是错的 ——
   在「我读到的其实是空表」这个前提上 `put`，结果就是把整份真配置清空。
   牙齿：`users.test.ts`（`users.json` 写坏 / `disabled` 非布尔 → fail-closed 到整份表）、
   `acl.test.ts`（`acl.json` 写坏 → 整份作废）。
③ **退出码三档互不重叠**：`0` 成功 / `1` 命令没错但没做成 / `2` 敲错了重敲。分开是给脚本用的，
   合成一个码的话脚本只能去 grep stderr 文本。四档都在判这一条（各自挑自己那一格），
   而「建议里必须含对方真正想写的那个」是它的可判定形式。
④ **不许悄悄弄丢别人的配置**：`AccountSource.put` 的注释自己点过名「这是本仓最容易造成
   「配额莫名其妙没了」的一个动作」，而 CLI 正是把那个动作摆到人面前的地方。
   `user add` 遇已存在的账号**直接拒绝**，`set` / `disable` / `enable` / `passwd` 一律
   **读-改-整条写回**且未指定字段逐字保留（`user enable` 把 `disabled` 显式写回 `false`
   而不是删键 —— 那是运维刚写下的意图）。牙齿：`users.test.ts`。
⑤ **临时目录隔离 + 不继承宿主环境**：每一档都在 `mkdtemp` 出来的空目录里跑，而 `run()` 的 `env`
   **刻意只给** `NODE_ENV=development` 与该档显式注入的那几键，**不继承宿主 `process.env`** ——
   否则仓库根 `.env.development` 的 `AUTH_*` / `PROXY_PROTOCOL` 会静默进档。
   牙齿在 `_admin-cli.ts` 的 `beforeEach` / `afterEach` 与 `run()`，五档全部经它们。

## 文件（⚠️ 不变量 ↔ 位置对照）

- `args.test.ts` — **不变量 ③ + ①**。用法错的三种形态与解析期的自我约束：退出码 `2` 必须**点名**
  （未知命令要列出全部可用子命令，未知 flag 要列出本命令认识的全部 flag 且含真正想写的那个，
  位置参数个数不对要指名多了什么），`--help` 在任何位置都优先，`--flag=value` 与 `--flag value`
  等价。
- `users.test.ts` — **不变量 ② + ④ + ①**。账号写族的字段保全（`add` 撞名拒绝 / `disable` /
  `enable` / `passwd` / `set` 逐字保留未指定字段）、读面坏内容硬失败、`--expires` 判据来源，
  外加 json / sqlite 两档后端的行为一致性。
- `acl.test.ts` — **不变量 ① + ②**。`AclSource.write` 是**可选成员** → 写面缺失必须响亮硬失败；
  组名 / 名单方向 / 条目语法三层都在写之前挡住；名单呈现必须**一条目一行**且行宽与规模无关。
- `read-only.test.ts` — **不变量 ③**。`config show` 打的是哪三份数据（路径 + 驱动名 + 配置目录，
  且 sqlite 档打 `AUTH_USERS_DB` 而不是 `AUTH_USERS_FILE`）、`usage` 只读且必须说清它**不能清账**
  及其原因、jwt 模式下改完要当场提醒字段不生效而只读命令不提醒。
- `source-guards.test.ts` — **层不变量 + 通道纪律**。源码级：零 `@/core` / `@/runtime` /
  `@/server` import（**绝不启动代理**）、零 console / 零 `process.*`、`loadConfig` 那个调用点的
  `argv` 必须是 `[]`、跳过启动期文件校验、`config show` 用与 CLI 同一份接线；
  通道：成功提示走 stderr 且 stdout 干净；组合根：`import` 零副作用。
- `_admin-cli.ts` — **不变量 ⑤ 的实现**（临时目录回收 / 写入面 / `run()` / 账号基准）。
- `AGENTS.md` — 本文件。

## 防假绿的位置

- ⚠️ **写入面断言的是「文件必须逐字未变」**而不是「解析后相等」：数据源层会归一，解析后相等会让
  「改写真的发生过、只是长得一样」也绿。
- ⚠️ **名单呈现钉「行宽上界」而不是某几行逐字相同**：上界是对**规模**的断言（40 条与 400 条同样过），
  把 `join(", ")` 塞回任何一格都立刻破它；逐字快照只锁住今天这 40 个域名，换个测试数据就绿。
  ⚠️ **拆掉哪一处会红**：`renderSections` 被换回「一格 join(", ")」的表格（`acl show` 与 `user show`
  都经它，故两条都红）；或者 `items` 改成只打条数不打条目。反向的那一格（「每个条目的主人是它上面
  那一行」）另钉归属，否则**宽上界仍绿** —— 那是这两条断言缺一不可的原因。
- ⚠️ **每条 for 循环型源码判据各自带一份扫描面下界**（两条各钉 `toolFiles` 含 `admin/index.ts` 与
  `ops/sources.ts`）：扫描范围由 `sourceFiles("admin", "ops")` **现列**（新增文件自动入范围），而
  for 循环若拿到空数组就整条恒绿 —— 那正是「护栏看起来在生效、实际什么都没扫」。
  ⚠️ **下界不许抽到一处共用**：共用之后删掉任何一条都照样绿。**列目录而不是写死文件名**是
  这里唯一的牙齿来源：手写清单会让「将来新增的那个」默认逃出护栏。
- ⚠️ **`requireAclWrite` 必须带正向对照**：只读驱动抛错这一格之外，还要一条「有写面的驱动 →
  返回一个可调用的函数」，否则「探测路径本身坏了」与「探测路径正确地拒绝」在断言上不可区分。
- ⚠️ **`sqlite` 档的负向输入必须选一个该档独有的判据**：直接写坏库文件是不可能的（doc 列是整条
  文档），所以走「形状非法的账号」路径（非法条目语法的个人名单）—— 不是 json 档那些搬过来能用的输入。
- ⚠️ **`ACCOUNT_WITH_EVERYTHING` 的基准形态是归一后的磁盘形态**（带 `.000Z` 的 UTC 串）：
  用它的那些档断言的是「**别的键逐字未变**」，基准本身不对就整组无意义。
- ⚠️ **`__dirname` 不许在本目录出现**：走出 `tests/` 的相对路径一律从
  `../../../helpers/source-scan.ts` 的 `SRC_DIR` 派生（层数只许出现在那一处）。

## 相关路径

- `src/admin/` — 传输层：`args.ts`（解析 + 退出码）/ `index.ts`（`runAdminCli` 派发）/ 渲染。
- `src/ops/` — 数据源操作层：`sources.ts`（装配 / `loadConfig` 调用点）/ `requireAclWrite` / 账本读 /
  `reportConfig`；「为什么 `usage` 不能清账」的完整推导在 `src/ops/usage.ts` 文件头。
- `src/cli-admin.ts` — 组合根（产物 `proxy-cli`）；与 `src/cli.ts`（产物 `proxy`）是两个组合根。
- `../../../helpers/source-scan.ts` — 源码级断言的公共文本面（`codeOnly` / `codeOf` / `sourceFiles` /
  `SRC_DIR`）。
- `../../../helpers/public-hosts/unit-admin.ts` — 本目录的零外网白名单片（**三档**
  `_admin-cli.ts` / `acl.test.ts` / `users.test.ts` 各一条，另两档零公网字面量故不建条目）。
- `tests/unit/ops/*.test.ts` — `src/ops/` 的结构化返回值与 `applyPatch` 那一面（在本目录之外，不重复）。
