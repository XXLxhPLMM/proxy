# src/store/ — zustand 状态分层

`app-store.ts` 只放形状与常量。五个 slice 各管一域，零 IO：

| 目录 | 管什么 |
|---|---|
| `sessions/` | 会话清单、当前会话、历史快照、侧边栏归属、滚动与发号 |
| `ledger/` | 台账、台账错误、provider 与模型清单、探活、账号 |
| `window/` | 弹窗、表单、改名框、菜单、高亮与过滤 |
| `exec/` | 执行队列、忙闲、执行中与模型对话标志 |
| `ui/` | 瞬时消息、输入历史、悬停、侧边栏宽 |

`@/store/index.js` 是唯一出口。IO（读写库、探活、发请求）由调用方注入，store 只收结果。
