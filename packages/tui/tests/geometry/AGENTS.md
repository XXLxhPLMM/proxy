# tests/geometry/ — `@/lib/geometry`（屏幕几何）的纯函数断言

本目录回答「一串终端宽高 + 一份屏面事实 ⇒ 屏上每一个坐标与下标」。零 IO、零真实终端：`geometry()` 只读注入进来的宽高，
故这一档能逐字断言坐标、宽度与下标，而不必起一个 Ink 去截图。

## 按子题分的档

| 文件 | 覆盖 |
| --- | --- |
| `block-layout.test.ts` | ① 负坐标 · ② 各区首尾相接 · ⑧之二 各区高度之和 == 终端行数 · 结果区内容宽度 |
| `sidebar.test.ts` | ③ 侧边栏项的度量与容量 · 文字排版预算 · ④ 与主区之间那一列 · 会话菜单 |
| `hit-test.test.ts` | ⑤ 半开区间命中 · ⑥ 插入符按显示宽度 |
| `input-wrap.test.ts` | ⑦ 折行（绘制与命中测试共用的那一个出口）· `caretRowOf` / `caretFromWrappedPoint` |
| `input-frame.test.ts` | ⑧ 状态行恒在框外 · ⑨ 命令面板贴着输入框 |
| `window.test.ts` | 模态窗口：卡片 · 标题 · 右上角那枚 `esc` |

## 层不变量（九条，全目录共用）

1. 任何终端尺寸下都不许出现负坐标；
2. 各区域首尾相接、**不重叠也不留缝**（状态行底边 == 终端行数、`output` 底边 == 输入框顶边、
   输入框底边 == 状态行顶边）；
3. 侧边栏每项**恰好 2 行高**（`SESSION_ROWS`）且互不重叠，且**横跨整列**；
4. 侧边栏与主区之间**恒隔 1 列**（那一列**不属于任何一边**）；
5. 命中测试用**半开区间**（点整除边界归右边那个）；
6. 插入符定位按**显示宽度**算（点中文右半边不能落在它一半的位置）；
7. 输入**折行**：`rows` 恒 ≥ 1、按**显示列**断、**一个字符都不许丢**、光标落在折出来的那一行；
8. 输入框**随折行数长高**（框内 n 行 + 上下框 + 框外状态行 = 整块高度），
   而**状态行恒在框外**且宽度与框**同**；
9. 命令面板**贴着输入框的上边**、高度**至多**结果区内容行的 `PALETTE_MAX_RATIO`；
   「结果文本 + 面板 = 内容行数」是那条恒等式。

⚠️ 第 4 与第 8 条各挡一个**只有真终端才看得见**的退化：间隔列不见了的话侧边栏与主区在满屏上
是一条整块底色；而状态行混进框里的话它会与输入串**抢同一行**（而它不消失、输入串会）。

### 会话栏那一轮新增的四条（逐条实测，**四条全部转红**）

这一轮把侧边栏的度量整个换掉了（顶部不留白 + 项间空一行 + 缩进 3 + 缺省宽 32），
于是「步长」与「容量」这两处算式必须**各自**有判据 —— 否则「常数改成 2」与「实现跟着改」会一起变。

| # | 变异 | 转红的判据 |
| --- | --- | --- |
| P1 | 第一项之下移一行（顶部加一格留白） | ③「逐项下移 SESSION_STRIDE 行」+「**贴着顶边**」+「恰好装满」+「差一行」+「首行不可见」+「关闭那一枚」—— **六条同时转红** |
| P2 | 项的 y 用 `SESSION_ROWS` 而不是 `SESSION_STRIDE` | ③「逐项下移 SESSION_STRIDE 行」+「恒隔一行」+「恰好装满」+ ⑤「命中下标就是会话下标」—— **四条同时转红** |
| P3 | `sessionCount === 0` 时仍给一个宽 32 的矩形 | ③「**一个会话都没有 ⇒ 整个侧边栏不存在**」+「太窄的屏整个侧边栏不画」—— **两条同时转红**（后者顺带逮到：`sidebar` 一旦不再是 `null`，那条判据的探针也变了） |
| P4 | `menuRect` 不夹进屏内（去掉那两个 `Math.min`） | 「贴着右下角的一次右键 ⇒ 整块菜单**留在屏内**」 |

## 判据为什么这么写（三条，各自有牙齿）

- ⚠️ **判据写算式、不写常量**：拿 `SESSION_STRIDE` / `MENU_MIN_WIDTH` / `WINDOW_WIDTH_RATIO` 当期望值的话，
  「改常量」与「改实现」同时发生 ⇒ 恒绿。故期望值一律现算（按 `columns` / `rows` 算）或写字面量。
- ⚠️ **宽度按内容现算**（菜单宽度 = 最长那一项的显示列 + 缩进；折行按 `stringWidth` 而非 `String.length`）：
  按字面量写死的话，改文案就红，而文案本来就不该被算术锁住。
- ⚠️ **「不画」必须是 `null` 而不是 0 宽的矩形**：命中测试拿着一份「有一个 0 宽区域」的数据时，
  点下去会静默无响应（0 宽的矩形恒不命中，而它还会白吃掉一次点击）。
