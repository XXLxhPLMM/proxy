# tests/geometry/ — `@/lib/geometry`（屏幕几何）的纯函数断言

本目录回答「一串终端宽高 + 一份屏面事实 ⇒ 屏上每一个坐标与下标」。零 IO、零真实终端：`geometry()` 只读注入进来的宽高，
故这一档能逐字断言坐标、宽度与下标，而不必起一个 Ink 去截图。

⚠️ 它**读源码文本**（不是跑起来的东西），故与本目录其余那几档零重叠。

## 层不变量（九条，全目录共用）

1. 任何终端尺寸下都不许出现负坐标；
2. 各区域首尾相接、**不重叠也不留缝**（状态行底边 == 终端行数、`output` 底边 == 输入框顶边、
   输入框底边 == 状态行顶边）；
3. 侧边栏每项**恰好 2 行高**（`SESSION_ROWS`）且互不重叠，且**横跨整列**；
4. 侧边栏与主区之间**恒隔 1 列**（那一列**不属于任何一边**）；
5. 命中测试用**半开区间**（点整除边界归右边那个）；
6. 插入符定位按**显示宽度**算（点中文右半边不能落在它一半的位置）；
7. 输入**折行**：`rows` 恒 ≥ 1、按**显示列**断、**一个字符都不许丢**、光标落在折出来的那一行；
8. 输入框**随折行数长高**（框内 n 行 + 上下框 + 框外状态行 = 整块高度），
   而**状态行恒在框外**且宽度与框**同**；
9. 命令面板**贴着输入框的上边**、高度**至多**结果区内容行的 `PALETTE_MAX_RATIO`；
   「结果文本 + 面板 = 内容行数」是那条恒等式。

⚠️ 第 4 与第 8 条各挡一个**只有真终端才看得见**的退化：间隔列不见了的话侧边栏与主区在满屏上
是一条整块底色；而状态行混进框里的话它会与输入串**抢同一行**（而它不消失、输入串会）。

## 判据为什么这么写（三条，各自有牙齿）

- ⚠️ **判据写算式、不写常量**：拿 `SESSION_STRIDE` / `MENU_MIN_WIDTH` / `WINDOW_WIDTH_RATIO` 当期望值的话，
  「改常量」与「改实现」同时发生 ⇒ 恒绿。故期望值一律现算（按 `columns` / `rows` 算）或写字面量。
  ⚠️ 同一条纪律的实测版：窗口高度那条判据原先用 28 行的屏，而「屏高一半 = 14」与「最小 15 行」同值 ⇒
  比例项删掉照样绿；改用 50 行（比例 25 > 下限 15）之后才转红。
- ⚠️ **宽度按内容现算**（菜单宽度 = 最长那一项的显示列 + 缩进；折行按 `stringWidth` 而非 `String.length`）：
  按字面量写死的话，改文案就红，而文案本来就不该被算术锁住。
- ⚠️ **「不画」必须是 `null` 而不是 0 宽的矩形**：命中测试拿着一份「有一个 0 宽区域」的数据时，
  点下去会静默无响应（0 宽的矩形恒不命中，而它还会白吃掉一次点击）。

⚠️ **侧边栏的度量（顶部留白 + 项间空一行 + 名字起始列 3 + 记号位宽）换了三处，于是「步长」「容量」
「记号位宽」这三处算式必须各自有判据** —— 否则「常数与实现一起改」会一起变而恒绿。
⚠️ 而「顶部留白」与「末尾那一行说明」**必须分开判**：把两者一起从容量里扣掉的话，「恰好装满」与
「极矮屏」那几档仍然全对（两项都错得一样多）。
⚠️ 折行那条同理：**丢字符**与**多出一行空行**是两个判据 —— 折行判据里 `index > start` 那个半边挡的是
**空行**，不是丢字符。
⚠️ 记号位宽**恒是奇数**：偶数列时两侧各 1 列 + 字形 = 3 列而预算是 2，多出来那一格落进右侧 ⇒
「每一行仍然等宽」与两条宽度断言一起转红，而症状是**「那一列宽出一格」**而不是「某一行多出一个字」。

## 源码级那一档（`layer-boundary.test.ts`）为什么这么写

- ⚠️ **零 `process.*` / 零 `console.*` / 零真值 import 是三组**负向**断言，而负向断言的经典失败模式是
  判据写坏了却恒绿（根 `AGENTS.md`「写护栏时」）。故三组各配一条**自检**：把同一套判据喂进**合成的
  违规文本**，要求它必须判中 —— 「探测器看得见」与「今天真的干净」两条合起来才叫断言。
  ⚠️ 还配一条**反向**自检（`obj.process.exit` / `obj.console.log` 不算违规，`import type` 不算违规）：
  防的是「判据过宽，什么都算违规」，那种过宽的判据会逼下一个人去放宽断言。
- ⚠️ **注释不算**（`codeOnly` 剔掉整行 `//` 与块注释后再扫）：注释里点名 `process.` 是在**描述**
  这条不变量，而不剔的话 `src/lib/AGENTS.md` 自己那一句就能把判据顶成恒红。
  ⚠️ **行尾 `//` 不剔**（源码里有 `http://` 那样的字符串）：宁可误报也不误判成「不是违规」。
- ⚠️ **React / Ink 那两档按「`import` 那一行不带 `type`」判，而不是按「不许引 `react`」判**：
  后者是技术锁定，换一种实现同一个不变量就被误判，于是下一个人会去改断言（形状同
  `tests/state-owner/state-owner.test.ts` 判据 2 的理由）。
- ⚠️ **锚点必须是今天仍然存在的路径**：扫描面那条点名 `geometry.ts` / `log/rows.ts` / `exec/run.ts`，
  且断言**递归**扫到两个子目录 —— 只扫顶层的话 `log/` 与 `exec/` 整个不在判据内，
  而「目录被搬走 ⇒ 锚点落空 ⇒ 恒绿」这个失败模式已经被根仓记过一次。
