# tests/endpoints/ — 端点表的自洽性与 `:username` 代入

本目录只答两件事：`@/api/endpoints/` 装配出来的那条平表**自洽吗**，以及 `@/lib/http.js:endpointPath`
把 `:username` 代入时**会拼出什么**。
机制与层不变量归 `packages/tui/src/api/AGENTS.md`（端点表是**手抄的弱耦合**：对面可能跑着旧版本服务端）。

## 文件

- `table.test.ts` — **字面量**那一侧：条数、`(method, path)` 无重复、形态合法、模板集合封闭。
- `substitution.test.ts` — **函数**那一侧：逐段编码、穿越边界、`..` 那个已知缺口、缺段即抛。
- `AGENTS.md` — 本文件。

## 为什么分两档：分界是**被测的东西是数据还是函数**

`table.test.ts` 只读 `ENDPOINTS`，从不调 `endpointPath`；`substitution.test.ts` 只调 `endpointPath`，
从不读 `ENDPOINTS`（`USER_TEMPLATE` 是**硬写**的字符串，不从表里取，故两边零耦合）。两档的**失败形态
也根本不同**：表漂了要去比路径集合，代入坏了要在 URL 上找症状。⚠️ 两边**零共享标识符**，故没有
`_*.ts` 可抽 —— 抽出来就是凭空多一跳。

## ⚠️ 两道牙各管一半，谁也不代替谁

- **路径集合**归根仓 `tests/unit/manager-tui-contract.test.ts`（**现列**两侧目录、从**源码文本**取
  `(method, path)` 再比集合）。本目录**不**比集合：`src/api/AGENTS.md` 记着「本目录的路径不许动」，
  而 `@/api/wire.ts` 的 `WireContractAssertions` 也是从源码文本现编译的。
- **字段形状**归 `packages/tui/tests/wire/`。本目录锁的是**本包这一侧的自洽性**（条数、
  `(method, path)` 不重复、形态合法）。

## 本目录盯的事故（按「错了会怎样」排序）

1. **端点表少一条 / 多一条 / 拼错方法名**。表是本包对控制面契约的完整声明；少一条 = 本包少
   一个功能，多一条 = 本包对着一个永远 404 的路径发请求，而两侧都「绿」。牙齿在仓库根的
   `tests/unit/manager-tui-contract.test.ts`（从两侧源码现取后比集合）；本目录只锁本包这一侧的
   自洽性（条数、`(method, path)` 不重复、形态合法）。
2. **`:username` 不编码 = 路径穿越 / 请求行被截断**。`/` 多切一段、`?` 起查询串、`#` 起片段
   —— 后两者会让服务端**根本收不到**那段用户名，而症状是「界面说没这个账号」。
3. **模板缺 `:username` 段时静默原样返回**。调用方拼错模板时，返回值长得完全像一个正常路径，
   于是错误一路走到服务端才以 404 的形态出现，指向一个无辜的端点。

## 判据为什么这么定

- **逐段判**而不是对整条路径判裸字符：路径本身必然含 `/`（`/api/users/...`），对整条判会让
  这条断言恒红 —— 恒红的断言等于没有断言（根 `AGENTS.md`「写护栏时」）。
- **编码结果与 `encodeURIComponent` 逐字比对**：不抄一份自己算的期望串（那就是第二份判据），
  直接断言 `encodeURIComponent(username)` 出现在结果里，且该段不含裸分隔符。
- **`..` 与 `:username` 后缀两处标注为已知缺口**并锁**实测形态**：本目录不把待裁决的分歧写成
  正向契约，也不用一条「反正会红」的断言假装护栏在生效（判据锚点必须锚在今天仍然存在的形状上）。
- **`..` 的症状是 404 而不是 400**，因为 `fetch` 的 URL 解析把 `/api/users/..` 消解成 `/api/`。
  锁它是为了让人知道**排查方向**：先怀疑地址，别怀疑权限，更别以为本端漏了编码。

## 防假绿的位置

- 「`(method, path)` 无重复」用 `Set.size === length`；**同时**独立断言条数是 12。少一个断言时，
  另一条仍在；两条都在时，加一条重复项会让两条同时红，而不是靠某一条偶然生效。
- 「同一路径上的多条只差方法」那条循环在路径全不重复时会**空转**，故点名当前确实存在的两条
  多方法路径（`/api/users` 与 `/api/acl`）各断言一次方法集合。
- 「模板缺段即抛错」断言的是**抛错**而不是错误文案：文案可以被重写，抛不抛是契约。
- 「`:usernames` 也抛」那条同时验**前缀形态**（`x:username`）：守卫与替换必须用**同一条**判据，
  用子串判的话它会通过守卫却原样返回 —— 返回值长得完全像一个正常路径。

## 相关路径

- `packages/tui/src/api/endpoints/` — 被测的平表（按服务端模块分段装配）。
- `packages/tui/src/lib/http.ts` — `endpointPath`。
- 根仓 `src/manager/routes/input.ts` — `requireSafeUsername`，`..` 那个缺口的**真闸门**在服务端。
- `packages/tui/tests/wire/` — 字段形状那一半。
