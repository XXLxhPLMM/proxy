# tests/exec/ — 执行层的档（`@/lib/exec/run.ts`）

一条命令 → 若干输出行 + 一组副作用，**逐字**断言。层的不变量与取舍归 `src/lib/exec/AGENTS.md`；这里只记
「这一圈断言守什么、怎么守」。

## 锁什么

**一条命令 → 若干输出行 + 一组副作用的语义规则**。它们全部是「显示的东西会不会不真实」的判据，
故每条都写成**能被反过来咬住**的形式：拿服务端给的原串去 `toBe`，拿「今天仍然存在的形状」去判「不该出现
的东西」（一个点名已删符号的负向断言会恒真，那是本仓点名的假绿）。

⚠️ **本目录没有「写」那一档，而那不是遗漏**：命令表里所有增删改都搬进弹窗了（零兼容，不留命令式的增删改），
而弹窗由状态层直接调读写面、**不经执行层** —— 于是本层**一个写动作都没有**，也**没有一条台账写的路径**。
⚠️ 而「一次写的结果怎么上屏」（`changed` / `notice` / `effective`）**还没有搬走**：判据在
`verbatim.test.ts` 的 ①②③，而它们**直接打渲染器**（`@/lib/exec/rows.js:changeRows`），因为命令那一族
已经不在表里。⚠️ 那三条判据的**下一个去处**是弹窗那一侧（谁拥有弹窗谁补），而渲染器本身今天在本目录
**没有生产调用方** —— 留着它是为了不删断言，不是因为它在跑。

**为什么拆掉哪一处会红**（每条后面的「变异」就是本目录跑过的那次真实转红）：

1. `changed: false` 走 `err` 分支 → 守 ① 那组红。
2. 删掉 `notice` 那一行 → 守 ② 那组红（少一句「这个键在 jwt 下不生效」）。
3. `effective` 无条件显示 → 守 ③ 那组红（一个字节没落盘却承诺生效）。
4. 把 `note` 换成自己编的一句 → 守 ④ 那组红（三段限定逐字）。
5. 把 `running: false` 当成异常抛出去 → 守 ⑤ 那组红（cluster master 是正常的）。
6. 给 `fileOrigin === undefined` 拼一个账本文件名上去 → 守 ⑥ 那组红（编文件名）。
7. 允许空表（只出表头）→ 守 ⑨ 那组红（「看起来正常、其实什么都没查到」）。
8. 直接打 `String(0)` → 守 ⑧ 那组红（`0` 字节是「不限量」，不是 `0`）。
9. 没有客户端时也发请求 → 守 ⑩ 那组红（对着 `0.0.0.0:0` 发一次是一句假事实）。
10. 把非 `TuiError` 的 message 转述出去 → `failures.test.ts` 红（那个串可能带得出下层的凭据）。
11. ⚠️ `/accounts` 改成 `client.users()`（而不是读注入进来的那一份）→ `no-target.test.ts`
    「一个请求都不发」红。

⚠️ **回显那条不变式分两半守**：「留痕的那些第一行必是回显」与「`/new` / 弹窗那一族一个字都不留、
而各自的 `Effect` 一字未改」。两半各自做过变异（把回显无条件加回去 / 把 `leavesTrace` 那一档说成
留痕，两组都转红），且**负向那一半带正向对照**（同一份 `deps` 下 `/help` 照样留痕）—— 否则
「`rows` 是空的」在 `exec` 整体坏掉时也成立。
⚠️ 而**回显逐字就是用户敲的那一串**：留痕的命令里**没有一条带凭据**（凭据只从弹窗的输入格进来，
而那一圈不回显），所以这一层**没有掩码分支**，`./rows.ts` 之外也不许有第二个打码出口。

⚠️ **客户端是替身，不是真 server**：`ManagerClient` 是 class，而 TS 的类**公开成员是结构化的**，
故一个只有那几个 public 方法的对象 `as unknown as ManagerClient` 就够。本包已有若干档对着真
`http.Server` 的测试（`tests/client/`），那一层的成本不在这里重复付。

## 档

| 文件 | 守哪几条 |
|---|---|
| `verbatim.test.ts` | ①–⑤：服务端给的那些字原样上屏（`changed` / `notice` / `effective` / `usage` 三段限定 / `runningMeans`）。⚠️ ①②③ 直接打 `@/lib/exec/rows.js:changeRows`（写命令已经不在表里） |
| `tables.test.ts` | ⑥ / ⑧ / ⑨ + 表的形状：读命令那一屏表，格子里只放服务端给的事实 |
| `failures.test.ts` | 一次控制面失败 → 一句话（`TuiError` 逐字 / `requestId` 不编 / 可重试多一句 / 非 `TuiError` 一个字都不转述）+ 「值域收窄归解析层」 |
| `no-target.test.ts` | ⑩：`client === null` 时一个请求都不发（仪器是全局 `fetch`，自带仪器自检）+ `/accounts` 那条纯读 |
| `local-commands.test.ts` | 不靠客户端的那几条命令、弹窗那一族的键位说明，与回显那一行 |
| `_shared.ts` | 替身 / 样本 / 断言工具（**不是**档，不被 `tests/**/*.test.ts` 收集） |

⚠️ **本目录没有「凭据不进任何一行」那一档，而那不是遗漏**：它随**带凭据的那几条命令**一起搬进了弹窗
（掩码走 `@/lib/log/rows.js:maskEcho`，而它今天在 `src/` 里**没有调用方**）。⚠️ **落盘那一份**
（`messages` 表的字节里没有明文凭据）仍在 `tests/sqlite/messages.test.ts` —— 而那一档今天用两条已经不
存在的命令造那份回显，**它需要跟着改**。

⚠️ **本目录没有 `/batch` 扇出的档，而这不是遗漏**：扇出由 `@/AppState.tsx:runBatch` 驱动，
执行层只把「内层那一条命令 + 那一批目标」递上去（`Effect:batch`），它自己不读台账也不发请求
（理由见 `src/lib/exec/AGENTS.md` 那三条取舍，扇出那一圈的档在 `tests/agent/`）。

## 拆档纪律

- ⚠️ **`_shared.ts` 的收件门槛是「两个以上档真用到」**，不是「看起来通用」：只被一档用到的东西
  （`configBody` / `aclBody` / `columnOf` / `fetchSpy`）就留在那一档里 —— 搬进来就成了
  一份没人能单独删掉、也没人说得清谁在用的间接层。
- ⚠️ **这里没有跨档共用的可变状态**，故拆档不改变任何一档的语义：两个替身都是**工厂**
  （`fakeClient` / `deps` 各自返回全新的计数器与全新的样本），改档的粒度不会让一个档
  的记录流进另一个档。
- ⚠️ 唯一动全局的是 `no-target.test.ts:fetchSpy` 换入的 `globalThis.fetch`，而它在**一条 `it` 内部**
  就换回（`try` / `finally`）、且只有那一档用它 —— 故它不进 `_shared.ts`。
- **不变量只写在本文件与各档自己的注释里，不复制进每个档**：复制的两份会各自腐烂，而腐烂的那份没人读。
