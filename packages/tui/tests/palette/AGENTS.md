# tests/palette/ — `@/commands/palette`（命令面板）的纯函数断言

被测模块在 `@/commands/palette.js`，零 IO、零渲染；面板的**几何**（占哪几行）在
`@/lib/geometry.ts`，**呈现**在 `@/app.tsx`，两者都不在这里。

⚠️ **命令名恒是一个词**（命令表里没有组，故命令名不跨空白）⇒ 「两段命令名的尾随空格」那一族问题不存在，
`PaletteRow` 上那个「补不补空格」的字段也没有了 —— 留着它就是一个恒假的字段（恒假的字段比没有更坏：
它看起来像一道还在生效的闸）。⚠️ 这条一旦不成立，「`Enter` 要按几下」那张表要重算。

## 各条负载在哪（改实现时看这张，而不是改完等它红）

- ① 去掉前缀那道闸 → 「不带前缀的行不开面板」红，且**没有**别处会红。
- ② 列表改成「按敲的东西过滤」→ 「`↓` 能一路走到底」红（填完 `/clear` 之后列表塌成一行）。
- ③ 高亮改成 `at` 自己累加 → 「高亮跟着输入行走」红。
- ④ `paletteFill` 改成替换**整行** → 「形参原样留着」红（`/usag| alice` 丢掉形参）；改成只换第一个词 →
  「光标在命令名中间」+「尾部形参一个字节都不许动」红；直接拼 `row.path` → 「不许把前缀写两遍」红。
- ④ **完全相同的那条不优先** → 「`/r` 高亮到 `/r` 本身」红：表里 `rename` 排在 `r` 前面，只按「以它开头」
  挑的话 `/r` 会高亮到 `/rename`，于是 `Tab` 补出一条他没敲的命令。**命令名取整行**（而不是第一个词）
  在新表上同样转红。
- ⑤ `paletteStep` 改成循环 → 「到头停住」红；`paletteWindow` 换成 `clamp` → 「高亮被顶到视口最后一行
  时才滚」红。
- ⑥ 见下节（它的判据形状本身就是一条独立的坑）。

## ⑥ `Enter` 那一档：判据是「这一行变没变」

**不能**按「命令名敲全了没」判 —— `/help` 敲全了高亮就是它自己，而按后一条判的话这条命令按多少次回车都跑不了
（症状是屏上**完全没有任何反应**的那一种）。**也不能**按「光标动没动」判（挪一下插入符不是一次补全），
更**不能**按「形参的值补没补」判（那是 `Tab` 的活，`complete()` 是它的另一个出口）。

⚠️ **判据里不许带光标**（`filled.line === line && filled.cursor === cursor` 那种形状）→「**同一个行、
两个光标、同一个结论**」红（`/usage ` @7 与 @6 必须是同一个 `submit`）+「两下之内到 `submit`」红。
⚠️ 这条**不能写成负向源码断言**（比对里不含光标那种文本判据对着一个已不存在的写法恒真），故判据是
「同一行 + 两个光标 + 一个结论」。

- 一律 `fill` → 真值表里三行 `submit` 红；一律 `submit` → 三档 `fill` 红。
- `Enter` 顺手调 `complete` → 「不做形参的值补全」红（它带一条正向对照：同一行 `Tab` **确实**补成另一行
  `/help status`，而 `Enter` 一行都不改）。
- 另抄一份接受逻辑（不调 `paletteFill`）→ 「共用 `paletteFill`」红（`Tab` 与 `Enter` 的补全各不相同）。
- `paletteFill` 的光标落在**行尾**或不自洽 → 「`fill` 之后插入符落在刚写进去那一段的末尾」红。

⚠️ **代价是数出来的，不是估出来的**（`enter.test.ts`「从敲第一个字到跑掉要按几下」那一档）：单段零形参
**1** 下、单段带形参 **1** 下、半截名字 **2** 下（补一次 + 提交一次 —— 跑掉的是补全出来的那一条，不是
他没敲完的那一条，否则「按一下就跑一条别的命令」）。⚠️ 那**一档逐条重算全表**（18 条命令）并按命令表
那份形参表分档，且**顺带把「全表只有那两档」本身钉住**（否则那张表钉的是同一档多遍）。
